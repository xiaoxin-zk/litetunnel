LiteTunnel Windows Client
=========================

Quick start
-----------
1. Keep LiteTunnel.exe and frpc.exe in the SAME folder.
2. Run LiteTunnel.exe.
3. Enter your console URL (e.g. https://panel.example.com), username and password.
4. Click "Connect". Tunnels are pulled from the server automatically.

Notes
-----
- This client stores only a revocable access credential, never your password.
- Config and logs live in %AppData%\LiteTunnel
- frpc.exe is bundled from the official frp release (Apache-2.0), see LICENSE-frp.txt
